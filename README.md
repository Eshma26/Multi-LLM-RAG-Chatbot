# Multi-LLM RAG Chatbot

An advanced Retrieval-Augmented Generation (RAG) chatbot built using LangChain, Groq Llama3, OpenAI APIs, Hugging Face models, and vector search pipelines.

This project demonstrates:
- Multi-LLM integration
- Conversational AI workflows
- Semantic document retrieval
- PDF question answering
- FastAPI deployment
- Vector database experimentation

## Tech Stack
- Python
- LangChain
- OpenAI
- Groq + Llama3
- Hugging Face Transformers
- FastAPI
- Vector Embeddings
- ObjectBox

## Features
- RAG-based chatbot architecture
- Conversational memory
- Semantic search pipelines
- PDF/document querying
- Modular AI workflows
- API-ready backend
